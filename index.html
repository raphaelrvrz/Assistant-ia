Comment installer ?

1
Clique sur le bouton "Installer l'Application" ci-dessus
2
Confirme l'installation dans la popup qui apparaît
3
L'app s'ajoute automatiquement à ton écran d'accueil avec l'icône 🤖
4
Configure ta clé API Anthropic dans les paramètres (⚙️)
5
Commence à discuter ! 🎉

🔧 Pour créer un fichier .apk

Si tu veux un vrai fichier .apk à installer comme les apps du Play Store :

  1. Héberge cette app sur Netlify (guide dans HEBERGEMENT.md)
  2. Va sur PWABuilder.com
  3. Colle l'URL de ton app Netlify
  4. Clique sur "Package For Stores" → Android
  5. Télécharge le fichier .apk généré
  6. Installe-le sur ton S21 !
